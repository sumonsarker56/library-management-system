# Library Management System (Java)

A simple yet professional Desktop-based **Library Management System** built using **Java Swing** and File Handling (`books.txt`).

## 🚀 Features
- **User Roles:** ADMIN and USER roles for different access levels.
- **Add Book:** Add new books with ID, Title, and Author (Admin only).
- **View All Books:** Displays all books cleanly in a structured **JTable**.
- **Search Books:** Quickly search for books by their title.
- **Issue & Return Books:** Update the status of any book to 'ISSUED' or 'AVAILABLE'.
- **Delete Book:** Easily delete records from the system (Admin only).
- **Data Persistence:** All book data is safely stored locally in a `books.txt` file.
- **Input Validations:** Automatic warnings for empty fields, duplicate IDs, or invalid actions.

## 🛠️ Technology Stack
- **Language:** Java
- **GUI Framework:** Java Swing (`JFrame`, `JTable`, `JPanel`, etc.)
- **Storage:** Text File Handling (`java.io`)

## ⚙️ How to Run
1. Make sure you have **Java JDK** installed on your system.
2. Clone or download this repository.
3. Open a terminal/command prompt in the project folder.
4. Compile the code:
   ```bash
   javac LibrarySystem.java
   ```
5. Run the application:
   ```bash
   java LibrarySystem
   ```
